# Vicious Download Manager (ViciousDM)

**Vicious Download Manager** (also written *ViciousDM*) is a free, fast download manager for Windows. It speeds up downloads by splitting every file into parallel parts, downloads videos and audio from many websites, includes a built-in torrent client and a link grabber, and comes with a browser extension for Chrome, Edge, Brave and Opera GX.

## What is Vicious Download Manager?

It is a Windows desktop app (also called a download accelerator) that takes over the downloads of your browser and finishes them faster and more reliably: big files are fetched over many connections at once, interrupted downloads continue where they stopped, and everything is kept in one list with queues, schedules and speed limits.

## Features

### Fast, reliable file downloads
- Multi-connection downloading: each file is split into up to 32 parallel parts, and the parts are re-split on the fly so no connection sits idle.
- Pause and resume with byte-accurate continuation, also after a restart or when the internet drops and returns.
- Queues for files, videos and torrents, with a limit on simultaneous downloads and queues that open and close at set times.
- Speed limits for all downloads together, and for a single download.
- Change link: continue an unfinished download from a new address when the old one expired.
- Disk space check before a download starts; files with a taken name are saved as "name (1)", "name (2)" and so on.
- Download categories with a separate save folder for each.
- Option to shut down the computer when a queue or a single download is finished (with a 60 second warning).
- Incognito downloads that leave no record in the history.

### Video and audio downloader
- Download video from many websites with a choice of quality, and the size of each quality shown before you start.
- Download audio only (MP3, M4A and more): a "Download this audio" button appears on pages that play music.
- Streaming (HLS) links with size and remaining time estimates.

### Built-in torrent client
- Magnet links and .torrent files.
- Choose which files to download, switch files on or off while the torrent runs, and mark files to be downloaded first.
- Speed limit, seeding that stops at a share ratio, and an option to keep or delete the files when a torrent is removed.
- Tracker list management.

### Link Grabber
- Paste links, playlist addresses or scan a web page to collect links.
- Group links into packages, filter by site, file type and availability, and download them together into a folder of your choice.
- Links sent by websites (Click'n'Load) arrive in the Link Grabber.

### Browser extension
- Chrome, Edge, Brave and Opera GX are supported.
- Takes over browser downloads and sends them to the app.
- Download button on web video players, with a choice of quality.
- Right-click menu on links, images and videos.
- Excluded Sites: list websites the app should leave alone.
- Settings > Browser Integration shows the status of the extension in each browser and helps install or update it.

### Everything else
- System tray with quick pause and resume, start with Windows, notifications and small pop-up windows for progress and completion.
- Filter and search the download list, previews for finished images and videos, drag and drop of links and .torrent files.
- Deleted files go to the Recycle Bin.
- Export and import of settings, queues and the download list.
- Several themes and accent colours.
- Updates itself, and shows what is new after every update.

## Installation

1. Download **ViciousDM-Setup** from the [latest release](https://github.com/Asad1224/Vicious-Download-Manager-releases/releases/latest) and run it.
2. To use the browser extension, download the extension zip from the same release (or use the Install button in Settings > Browser Integration), turn on Developer mode on the browser's extensions page, and load the extension folder.

## Frequently asked questions

**Is Vicious Download Manager free?** Yes, it is free to download and use.

**Which browsers does it work with?** Chrome, Edge, Brave and Opera GX through the included extension. Firefox is not supported yet.

**Does it work on Mac or Linux?** Not yet. A Mac version is planned.

**How do I update?** The app checks for new versions by itself; Settings > About shows the state and lets you update at once.

**Where do I report a problem?** Open an issue in this repository. Settings has a log of recent warnings and errors with a Copy button, which helps a lot.
